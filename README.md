# NoTicket

No Ticket helps you find free parking in San Francisco with data you can actually trust. It’s a lightweight, single-file site that shows cleaned, verified free-parking windows and blockfaces.

# How it works
We start with crowdsourced inputs (spots and blockfaces), then verify them using browser-use sessions and Google Street View to confirm signage, time windows, street cleaning, and permit zones. We also pull official rules from SF parking meters and aggregate them to understand when meters don’t apply (i.e., truly free windows). The result is a dataset that’s far more reliable than raw crowdsourcing.

# Using the project
*	Open index.html in any modern browser.
*	That single file renders the cleaned dataset and map UI.
